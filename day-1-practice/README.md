## HTTP Methods

- GET: Retrieve data.
- POST: Create data.
- PUT: Update existing data.
- PATCH: Partially update data.
- DELETE: Delete data.

## HTTP Status Codes

- 200: OK
- 201: Created
- 400: Bad Request
- 401: Unauthorized
- 403: Forbidden
- 404: Not Found
- 500: Internal Server Error
